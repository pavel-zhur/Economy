# Budget Tracker Interpretation Guide

## Transaction Types
- expense: Money spent on goods or services
- income: Money received (salary, freelance, etc.)
- transfer: Moving money between accounts

## Categories
- food_dining: Restaurants, coffee shops, takeout
- housing: Rent, mortgage, utilities
- transportation: Gas, public transit, car expenses
- shopping: General purchases and retail

## Guidelines
- Extract amounts as numbers without currency symbols
- Infer merchant from context when mentioned
- Use clear, concise descriptions
- Default account to "checking" if not specified
