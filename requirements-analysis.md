# Анализ зависимостей requirements.txt для POC 3

## Проблемы с текущими версиями

### Критические проблемы:

1. **LangChain версии крайне устаревшие:**
   - `langchain==0.0.350` → должна быть `0.3.25` (разница в 75+ минорных версий!)
   - `langchain-openai==0.0.2` → должна быть `0.3.23` (разница в 321+ минорных версий!)
   - `langchain-community==0.0.8` → должна быть `0.3.16` (разница в 308+ минорных версий!)

2. **OpenAI SDK устаревший:**
   - `openai==1.3.0` → должна быть `1.86.0` (разница в 83 минорных версии!)

3. **FastAPI и Pydantic устаревшие:**
   - `fastapi==0.104.1` → должна быть `0.115.12` (разница в 11 минорных версий)
   - `pydantic==2.5.0` → должна быть `2.10.5+` (разница в 5 минорных версий)

4. **LangFuse устаревший:**
   - `langfuse==2.9.0` → должна быть `2.57.0+` (разница в 48 минорных версий!)

### Основные риски:

1. **Несовместимость API:** Старые версии LangChain имеют кардинально другой API
2. **Уязвимости безопасности:** Старые версии содержат известные CVE
3. **Отсутствие функций:** Многие новые возможности недоступны
4. **Конфликты зависимостей:** Старые версии могут не работать с Python 3.13

## Необходимые изменения в коде

При обновлении до новых версий потребуются изменения:

### 1. LangChain API изменения:
```python
# Старый API (0.0.x)
from langchain.llms import OpenAI
from langchain.schema import HumanMessage

# Новый API (0.3.x)
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage
```

### 2. OpenAI SDK изменения:
```python
# Старый API (1.3.x)
import openai
openai.api_key = "..."

# Новый API (1.86.x)
from openai import OpenAI
client = OpenAI(api_key="...")
```

### 3. Pydantic изменения:
```python
# Старый API (2.5.x)
class Config:
    extra = "forbid"

# Новый API (2.10.x)
model_config = ConfigDict(extra="forbid")
```

## Степень критичности

🔴 **КРИТИЧНО - Немедленные действия требуются:**

1. **Система не будет работать с Python 3.13+**
2. **Множественные уязвимости безопасности**
3. **API несовместимость приведет к ошибкам**
4. **Отсутствие современных AI функций**

### Временные затраты на обновление:
- **Малые:** 2-4 часа (только обновление версий)
- **Средние:** 1-2 дня (с тестированием и исправлением API)
- **Крупные:** 3-5 дней (полное тестирование и документация)

## Пошаговый план обновления

2. **Обновить requirements.txt**

4. **Установить новые зависимости**
5. **Исправить импорты и API вызовы**
6. **Протестировать каждый модуль**
7. **Интеграционное тестирование**
8. **Документировать изменения**
