# 🏦 AI Financial Planning System - POC 1

AI-управляемая PostgreSQL база данных для системы финансового планирования. Система позволяет AI полностью управлять SQL базой данных - от интерпретации свободных сообщений пользователей до создания схем, записи данных и выполнения миграций.

## 🎯 Основные возможности

### 📊 Планирование
- Создание и управление финансовыми планами (расходы/накопления/фонды)
- Постановка и отслеживание финансовых целей
- Автоматическое распределение доходов по планам
- Иерархическая структура планов

### 💰 Учет транзакций
- Запись реальных доходов и расходов
- Связывание транзакций с планами
- Управление кошельками и счетами
- Инвентаризация балансов

### 📈 Анализ и отчетность
- Автоматическое построение отчетов
- Анализ прогресса по целям
- Выявление отклонений от планов
- Прогнозирование финансового состояния

### 🔧 AI-управление данными
- Понимание естественного языка
- Автоматическое создание схем БД
- Выполнение миграций данных
- Адаптация структуры под запросы

## 🏗️ Архитектура

### Технический стек
- **PostgreSQL 16** - основная база данных
- **LangGraph** - оркестрация multi-agent workflows
- **LangChain SQL Agent** - AI интерфейс к PostgreSQL
- **OpenAI GPT-4** - языковая модель
- **Chainlit** - chat интерфейс
- **LangFuse** - трассировка LLM операций
- **Alembic** - миграции БД
- **Redis** - кэширование
- **MinIO** - файловое хранилище
- **Prometheus + Grafana** - мониторинг

### AI Агенты
1. **SQL Agent** - базовые операции с БД
2. **Planning Agent** - финансовое планирование
3. **Analysis Agent** - аналитика и отчеты
4. **Schema Agent** - модификация структуры БД

## 🚀 Быстрый старт

### 1. Предварительные требования
- Docker и Docker Compose
- OpenAI API ключ

### 2. Клонирование и настройка
```bash
cd "playgrounds/poc 1"

# Создайте .env файл на основе примера
cp .env.example .env

# Отредактируйте .env файл, добавив ваш OpenAI API ключ
nano .env
```

### 3. Запуск системы
```bash
# Запуск всех сервисов
docker-compose up -d

# Просмотр логов
docker-compose logs -f ai-finance-app
```

### 4. Доступ к интерфейсам

- **Chainlit Chat Interface**: http://localhost:8000
- **pgAdmin (БД)**: http://localhost:8080 (admin@example.com / admin123)
- **LangFuse (Трассировка)**: http://localhost:3000
- **Grafana (Мониторинг)**: http://localhost:3001 (admin / admin123)
- **MinIO (Файлы)**: http://localhost:9001 (admin / admin123)

## 🗄️ Модель данных

### Слой планирования (виртуальный)
- **plans** - финансовые планы с иерархией
- **planned_operations** - планируемые доходы/расходы
- **goals** - финансовые цели
- **distribution_rules** - правила автораспределения

### Слой фактических данных  
- **wallets** - кошельки и счета
- **transactions** - реальные транзакции
- **wallet_inventories** - инвентаризации балансов

### Системный слой
- **plan_balances** - расчетные балансы планов
- **system_logs** - журнал операций AI
- **assets** - немонетарные активы
- **debts** - выданные займы

## 🐛 Отладка

### Распространенные проблемы

1. **OpenAI API ошибки**
   - Проверьте API ключ в .env файле
   - Убедитесь в наличии средств на аккаунте

2. **Ошибки подключения к БД**
   - Проверьте статус PostgreSQL контейнера
   - Убедитесь в корректности DATABASE_URL

3. **Проблемы с агентами**
   - Просмотрите трассировку в LangFuse
   - Проверьте логи приложения

### Получение помощи
```bash
# Проверка статуса сервисов
docker-compose ps

# Просмотр детальных логов
docker-compose logs ai-finance-app

# Подключение к контейнеру для отладки
docker-compose exec ai-finance-app bash
```
