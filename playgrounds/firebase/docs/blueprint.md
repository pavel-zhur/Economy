# **App Name**: FinTrack Vision

## Core Features:

- Financial Overview: Dashboard providing an overview of financial plans, actual spending, and progress toward goals.
- Income Distribution Visualizer: Tool for visualizing income distribution across different plans and expense categories over time, both past and projected.
- Savings Goal Tracker: Display current progress toward savings goals, factoring in planned contributions and actual savings to date. Display a graph showing the goal and past trajectory. Predict possible futures.
- Issue Identification: Provide a view of plans with negative balances and transactions not linked to a financial plan to highlight potential issues.
- Planning Interface: Interface for planning and managing incomes, recurring payments and goals.
- Smart Allocator: Generative AI tool that suggests how to allocate incomes to different plans according to what the user wants to achieve.
- "What-if" Scenario Modeler: Allows users to define different scenarios and generate a visualization that estimates if the planned allocation strategies allows to achieve short and long term goals. Use generative AI to come up with more options.

## Style Guidelines:

- Primary color: Vivid blue (#4285F4) for a trustworthy and reliable feel.
- Background color: Light gray (#F5F5F5) for a clean and modern look.
- Accent color: Soft green (#34A853) to indicate progress and positive changes.
- Body and headline font: 'Inter' sans-serif for clear, objective readability.
- Use minimalist, outline-style icons related to finance.
- Clean, grid-based layout with an emphasis on white space to prevent clutter.
- Subtle transitions and animations to provide feedback and guide the user.
