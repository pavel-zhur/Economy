# Financial Planning System

Система финансового планирования для осознанного управления личными финансами. Позволяет планировать, отслеживать фактические данные и анализировать финансовые потоки для достижения поставленных целей.

## Возможности

- **Управление планами**: Создание и управление планами накоплений, трат и фондов
- **Отслеживание транзакций**: Учет доходов и расходов с возможностью привязки к планам
- **18 аналитических представлений**: От планируемых расходов до прогнозирования на год
- **Моделирование "Что если"**: Интерактивное прогнозирование последствий изменений
- **Цели накоплений**: Отслеживание прогресса достижения финансовых целей

## Технологический стек

- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS
- **UI Components**: shadcn/ui
- **Backend**: Next.js API Routes (мок-данные в памяти)
- **Дата**: date-fns для работы с датами
- **Иконки**: Lucide React

## Представления (Views)

Система включает 18 аналитических представлений:

1. **Планируемые расходы** - прошлые и будущие расходы
2. **Распределение фактических денег** - текущее распределение средств по планам
3. **Будущее распределение по фондам** - прогноз накоплений (✅ реализовано)
4. **Распределение доходов** - анализ распределения доходов по планам
5. **Инвентаризация** - сверка балансов кошельков
6. **Время задержки средств** - анализ времени использования денег
7. **Планы с отрицательным балансом** - проблемные планы и неподкрепленные транзакции (✅ реализовано)
8. **Баланс планов во времени** - динамика балансов планов
9. **Цели накоплений и прогресс** - отслеживание достижения целей
10. **Моделирование "Что если"** - интерактивное прогнозирование (✅ реализовано)
11. **История отклонений от плана** - анализ расхождений план/факт
12. **Остаток до следующего дохода** - анализ достаточности средств
13. **Эффективность планирования** - оценка успешности планов
14. **Нерегулярные доходы и расходы** - анализ разовых операций
15. **Календарь финансовых событий** - временная структура операций
16. **Анализ нереалистичных планов** - выявление завышенных ожиданий
17. **Прогноз на год (текущий образ жизни)** - долгосрочный прогноз
18. **Прогноз на год (с изменениями)** - прогноз с корректировками

## API Endpoints

### Планы
- \`GET /api/plans\` - получить все планы
- \`POST /api/plans\` - создать новый план

### Транзакции  
- \`GET /api/transactions\` - получить все транзакции
- \`POST /api/transactions\` - создать новую транзакцию

## Конфигурация Docker

### Dockerfile

Приложение использует многоэтапную сборку Docker:
- **Этап dependencies**: установка зависимостей
- **Этап builder**: сборка приложения
- **Этап runner**: финальный образ для запуска

### Docker Compose

Конфигурация включает:
- **Сервис app**: основное приложение на порту 3000
- **Volumes**: для кэширования node_modules
- **Environment**: переменные окружения для разработки

### Переменные окружения

Создайте файл \`.env.local\` для локальной разработки:

\`\`\`env
# Пример переменных окружения
NODE_ENV=development
NEXT_PUBLIC_APP_URL=http://localhost:3000
\`\`\`

## Разработка

### Добавление нового представления

1. Создайте новую страницу в \`app/view-X/page.tsx\`
2. Добавьте ссылку в \`components/layout/sidebar.tsx\`
3. При необходимости создайте новые API endpoints в \`app/api/\`
4. Добавьте необходимые типы в \`lib/types.ts\`

### Стилизация

Проект использует:
- **Tailwind CSS** для стилизации
- **shadcn/ui** для готовых компонентов
- **CSS Variables** для темизации

### Типизация

Все основные сущности типизированы в \`lib/types.ts\`:
- \`Plan\` - финансовые планы
- \`Transaction\` - транзакции
- \`ForecastPoint\` - точки прогноза
