# Система финансового планирования

React SPA приложение для управления личными финансами с возможностью планирования, отслеживания фактических данных и анализа финансовых потоков.

## Функциональность

### Реализованные представления данных:

1. **Дашборд** - общий обзор финансового состояния
2. **Планируемые расходы** - просроченные и предстоящие платежи
3. **Распределение денег** - текущее распределение средств по планам
4. **Инвентаризация кошельков** - сверка балансов кошельков и транзакций
5. **Время задержки средств** - анализ времени от поступления до использования
6. **Планы с отрицательным балансом** - проблемные планы и неучтенные транзакции
7. **Прогресс по целям** - отслеживание достижения финансовых целей

### Заготовки для будущих представлений:

- Будущее распределение по фондам и накоплениям
- Распределение доходов по планам, расходам и категориям
- Баланс планов во времени
- И еще 8 представлений согласно требованиям

## Технологический стек

- **React 18** - основной фреймворк
- **Material-UI (MUI)** - компонентная библиотека
- **Recharts** - библиотека для графиков
- **React Router** - маршрутизация
- **date-fns** - работа с датами
- **Docker** - контейнеризация

## Запуск приложения

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start
```

Приложение будет доступно по адресу: http://localhost:3000

### Запуск с Docker (разработка)

```bash
# Запуск в режиме разработки
docker-compose --profile dev up --build

# Остановка
docker-compose --profile dev down
```

### Запуск с Docker (продакшен)

```bash
# Сборка и запуск продакшен версии
docker-compose --profile prod up --build

# Остановка
docker-compose --profile prod down
```

Продакшен версия будет доступна по адресу: http://localhost

## Основные сущности данных

- Балансы и цели

## Разработка

### Доступные скрипты

```bash

npm run build      # Сборка для продакшена
npm test           # Запуск тестов
npm run eject      # Извлечение конфигурации (необратимо)
```

### Docker команды

```bash
# Разработка
docker-compose --profile dev up -d
docker-compose --profile dev logs -f financial-app-dev

# Продакшен
docker-compose --profile prod up -d

# Очистка
docker-compose down --volumes --remove-orphans

```
