# Система финансового планирования

Комплексное React-приложение для управления личными финансами с акцентом на планирование, отслеживание и анализ финансовых потоков.

## 🎯 Цель проекта

Предоставить пользователю **осознанное управление** личными финансами через:
- Планирование доходов и расходов
- Отслеживание фактических данных
- Анализ отклонений и прогнозирование
- Мотивацию для достижения финансовых целей

## 🏗️ Архитектура системы

### Трехслойная модель данных:
1. **Слой планирования** - виртуальные планы, цели, сценарии
2. **Слой фактических данных** - реальные транзакции и инвентаризации
3. **Слой сверки** - связи между планами и фактом, актуализация расхождений

### Ключевые принципы:
- **Баланс сохранения денег** - деньги не появляются из ниоткуда
- **Трехсторонняя сверка** - кошельки = транзакции = планы
- **Иерархия планов** - древовидная структура с агрегацией
- **Воронка оценок** - сужение прогнозов по мере получения информации

## 📊 Основные экраны (24 всего)

### 🔥 Ключевые новые компоненты (Итерация 1):

#### 1. **Быстрое планирование** (`/quick-planning`)
- Трехэтапный мастер распределения доходов
- Готовые шаблоны (50/30/20, консервативный, агрессивный)
- Интерактивные слайдеры с автобалансировкой
- Визуализация через круговые диаграммы

#### 2. **Структура планов** (`/plan-tree`)
- Древовидная иерархия планов (аналог hot paths в профайлерах)
- Over/Under варианты с цветовым кодированием
- Планы-ограничения (constraint) для приоритетного контроля
- Агрегация расхождений вверх по иерархии
- Детали транзакций в модальных окнах

#### 3. **Управление транзакциями** (`/transactions`)
- Разделение: обычные транзакции vs виртуальные переводы
- Простая привязка транзакций к планам
- Предупреждения о непривязанных операциях
- Статистика по связанности данных

#### 4. **Сверка балансов** (`/balance-reconciliation`)
- Трехсторонняя проверка: кошельки ↔ транзакции ↔ планы
- Статусы сходимости (идеально/хорошо/предупреждение/ошибка)
- Развертываемые детали по каждому типу баланса
- История конвергенции с графиками

#### 5. **Актуализация планов** (`/plan-actualization`)
- Пошаговый мастер закрытия расхождений plan vs fact
- Обработка экономии (over) и перерасходов (under)
- Виртуальные переводы для сведения баланса
- История актуализаций с аудит-трейлом

#### 6. **Управление сценариями** (`/scenario-management`)
- Воронка оценок: пессимистичный/реалистичный/оптимистичный
- Редактируемые месячные взносы с уровнем уверенности
- Прогнозы накоплений с диапазонами неопределенности
- История сужения оценок во времени

## 🎨 Дизайн-система

### Цветовая схема:
- **Основной** (primary): Планы-фонды, навигация
- **Успех** (success): Накопления, положительные варианты
- **Информация** (info): Цели, виртуальные переводы  
- **Предупреждение** (warning): Расходы, требующие внимания
- **Ошибка** (error): Перерасходы, критические проблемы

### UX принципы:
- **Прогрессивное раскрытие** - от общего к деталям
- **Цветовое кодирование** - интуитивное понимание статусов
- **Контекстные действия** - кнопки там, где нужно
- **Минимум кликов** - быстрый доступ к частым операциям

## 🔄 Потоки данных

### Ключевые пользовательские сценарии:

1. **Планирование дохода**: QuickPlanning → PlanTreeView → ScenarioManagement
2. **Контроль расходов**: TransactionManagement → PlanTreeView → PlanActualization  
3. **Сверка данных**: BalanceReconciliation → TransactionManagement
4. **Анализ целей**: PlanTreeView → GoalsProgress → WhatIfAnalysis
