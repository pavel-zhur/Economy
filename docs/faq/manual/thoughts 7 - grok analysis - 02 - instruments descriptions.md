# Описание инструментов и интеграций для управления данными с AI

## Цель системы
Создать систему, где AI управляет базой данных PostgreSQL, интерпретируя свободноформатные данные (заметки, чаты) и структурируя их. Система поддерживает изменения схемы, миграции, воспроизведение данных и визуализацию изменений.

## Инструменты

### 1. PostgreSQL
- **Что это:** База данных для хранения данных в таблицах (строки и столбцы).
- **Зачем нужен:** Основное хранилище структурированных данных.
- **Задачи:**
  - Хранение таблиц (например, `users`: `id`, `name`, `email`).
  - Поиск (например, "найди заказы за октябрь").
  - Транзакции для целостности.
  - Поддержка JSON для неструктурированных данных.
- **Интеграция:**
  - PostgREST: Создает API на основе схемы.
  - LangChain: Выполняет SQL-запросы.
  - SQLAlchemy: Управляет схемой.
- **Пример:** Заметка "Петров купил за 500 рублей" → таблица `purchases`.

### 2. PostgREST
- **Что это:** Инструмент для создания API из PostgreSQL.
- **Зачем нужен:** Упрощает доступ к данным.
- **Задачи:**
  - API для CRUD-операций (например, `/users`).
  - Фильтрация (например, `/users?age=gt.25`).
  - Безопасность через JWT.
- **Интеграция:**
  - PostgreSQL: Читает схему.
  - Chainlit: Фронтенд запрашивает данные.
  - LangServe: Агенты используют API.
- **Пример:** `GET /orders?date=2023-10-15` → список заказов.

### 3. LangChain
- **Что это:** Библиотека для работы AI с данными.
- **Зачем нужен:** Переводит запросы на русском в SQL.
- **Задачи:**
  - Перевод "Сколько заказов?" в SQL.
  - Выполнение запросов.
  - Коррекция ошибок.
- **Интеграция:**
  - PostgreSQL: Подключается через драйвер.
  - LangGraph: Агенты внутри процессов.
  - LangServe: Доступ через API.
- **Пример:** "Добавь заказ на 300 рублей" → `INSERT INTO orders`.

### 4. LangGraph
- **Что это:** Инструмент для управления агентами.
- **Зачем нужен:** Координирует сложные задачи.
- **Задачи:**
  - Управление агентами (планирование, выполнение, проверка).
  - Контроль состояния.
  - Вмешательство человека.
- **Интеграция:**
  - LangChain: Использует агентов.
  - LangGraph Studio: Визуализация.
  - LangSmith: Логирование.
- **Пример:** Добавление поля "скидка" через агентов.

### 5. LangServe
- **Что это:** Превращает агентов в веб-сервисы.
- **Зачем нужен:** Доступ к агентам через интернет.
- **Задачи:**
  - Создание API (например, `/sql-agent`).
  - Потоковые ответы.
  - Безопасность.
- **Интеграция:**
  - LangChain: Делает агентов доступными.
  - Chainlit: Фронтенд общается с API.
- **Пример:** Запрос "Покажи заказы" → ответ через API.

### 6. Chainlit
- **Что это:** Веб-чат для общения с AI.
- **Зачем нужен:** Удобный интерфейс.
- **Задачи:**
  - Чат для запросов и ответов.
  - Потоковые ответы.
- **Интеграция:**
  - LangServe: Запросы к API.
  - PostgreSQL: Данные через агентов.
- **Пример:** "Сколько заказов?" → ответ в чате.

### 7. Open WebUI
- **Что это:** Альтернативный веб-интерфейс.
- **Зачем нужен:** Другой стиль общения с AI.
- **Задачи:**
  - Чат или формы.
  - Настройка интерфейса.
- **Интеграция:**
  - LangServe: Подключается к API.
- **Пример:** "Покажи продажи" → таблица.

### 8. LangGraph Studio
- **Что это:** Графический интерфейс для LangGraph.
- **Зачем нужен:** Отладка процессов.
- **Задачи:**
  - Визуализация шагов агентов.
  - Вмешательство.
- **Интеграция:**
  - LangGraph: Показывает графы.
  - LangSmith: Логи.
- **Пример:** Отладка миграции.

### 9. LangSmith
- **Что это:** Сервис мониторинга AI.
- **Зачем нужен:** Анализ работы агентов.
- **Задачи:**
  - Логирование запросов.
  - Поиск ошибок.
- **Интеграция:**
  - LangChain: Логи агентов.
  - LangGraph: Логи процессов.
- **Пример:** Анализ неверного запроса.

### 10. LangFuse
- **Что это:** Альтернатива LangSmith.
- **Зачем нужен:** Мониторинг с открытым кодом.
- **Задачи:**
  - Логи и статистика.
- **Интеграция:**
  - LangChain, LangGraph.
- **Пример:** Отслеживание ошибок.

### 11. Hasura
- **Что это:** Создает GraphQL API.
- **Зачем нужен:** Альтернатива PostgREST.
- **Задачи:**
  - GraphQL-запросы.
  - Real-time обновления.
- **Интеграция:**
  - PostgreSQL: Читает схему.
  - Chainlit: Данные через GraphQL.
- **Пример:** `{ orders { customer } }`.

### 12. Supabase
- **Что это:** Платформа "всё в одном".
- **Зачем нужен:** Упрощает настройку.
- **Задачи:**
  - База, API, аутентификация.
- **Интеграция:**
  - LangChain: Подключение к базе.
  - Chainlit: Использует API.
- **Пример:** Таблица `clients` с API.

### 13. SQLAlchemy
- **Что это:** Библиотека Python для баз.
- **Зачем нужен:** Управление схемой.
- **Задачи:**
  - Определение таблиц.
  - Миграции через Alembic.
- **Интеграция:**
  - PostgreSQL: Выполняет команды.
  - LangChain: Запросы.
- **Пример:** Класс `User` → таблица.

## Концепции

### Агенты
- Программы с AI для задач (SQL Agent, DDL Agent).
- Пример: "Добавь клиента" → `INSERT`.

### Оркестраторы
- Управляют агентами (LangGraph).
- Пример: Добавление категории через шаги.

## Интеграция
- PostgreSQL → PostgREST → LangChain → LangGraph → LangServe → Chainlit.
- Пример: Запрос "Покажи заказы" → SQL → результат в чате.

## Бизнес-логика
- Гибкость, автоматизация, контроль, доступность.
