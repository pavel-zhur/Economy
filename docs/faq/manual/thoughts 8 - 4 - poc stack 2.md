# POC Stack 2: "n8n All-in-One"

## Описание стека

Минималистичный подход для быстрого старта. n8n предоставляет всё необходимое "из коробки": визуальную оркестрацию, AI агентов, встроенный UI и мониторинг.

```
PostgreSQL + n8n + встроенные AI агенты + встроенный UI + встроенный мониторинг
```

## Основные компоненты

### 🗄️ База данных
- **PostgreSQL 16**: Основная база данных
- **pgAdmin**: Web-интерфейс для управления БД (опционально)

### 🤖 Центральная платформа
- **n8n**: All-in-one платформа включающая:
  - Visual workflow builder
  - AI агенты с LangChain под капотом
  - Встроенные PostgreSQL nodes
  - Chat интерфейс
  - Встроенный мониторинг и логирование
  - HTTP API для внешних интеграций

### 📊 AI модели
- **OpenAI**: LLM провайдер (через API)
- **Ollama** (опционально): Локальные модели

### 🔧 Дополнительные сервисы
- **Redis** (опционально): Для производительности n8n
- **MinIO** (опционально): Файловое хранилище

## Архитектура взаимодействия

1. **Пользователь** → n8n Web UI (visual workflows + chat)
2. **n8n** → AI агенты (встроенные)
3. **AI агенты** → PostgreSQL (через n8n nodes)
4. **n8n** → External APIs (OpenAI, Ollama)
5. **Встроенный мониторинг** → n8n execution logs

## Примеры use cases

### 1. AI SQL Assistant
- Пользователь задает вопрос на естественном языке
- n8n AI агент преобразует в SQL запрос
- Выполняет запрос к PostgreSQL
- Возвращает результат в понятном виде

### 2. Schema Evolution Agent
- Мониторинг изменений в данных
- AI анализ необходимости изменения схемы
- Генерация миграций
- Human-in-the-loop approval через n8n форм

### 3. Data Quality Monitor
- Периодическая проверка качества данных
- AI анализ аномалий
- Автоматические уведомления
- Предложения по исправлению
