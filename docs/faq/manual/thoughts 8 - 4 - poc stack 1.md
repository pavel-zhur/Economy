# POC Stack 1: "LangGraph Classic"

## Описание стека

Классический подход с максимальным контролем над каждым компонентом. Основан на LangGraph для оркестрации агентов с полным набором специализированных инструментов.

```
PostgreSQL + LangGraph + LangChain SQL Agent + Alembic + Chainlit + LangFuse
```

## Основные компоненты

### 🗄️ База данных
- **PostgreSQL 16**: Основная база данных с JSON/JSONB поддержкой
- **pgAdmin**: Web-интерфейс для управления БД

### 🤖 AI слой
- **LangGraph**: Оркестрация multi-agent workflows
- **LangChain SQL Agent**: AI интерфейс к PostgreSQL
- **OpenAI**: LLM провайдер (через API)

### 📊 Миграции и схема
- **Alembic**: Версионирование и миграции БД

### 🎨 Пользовательский интерфейс
- **Chainlit**: Chat интерфейс для взаимодействия с агентами

### 📈 Мониторинг и трассировка
- **LangFuse**: Трассировка LLM взаимодействий и аналитика
- **Prometheus**: Сбор метрик
- **Grafana**: Визуализация метрик

### 🔧 Дополнительные сервисы
- **Redis**: Кэширование и очереди задач
- **MinIO**: S3-совместимое хранилище для файлов

## Архитектура взаимодействия

1. **Пользователь** → Chainlit UI
2. **Chainlit** → LangGraph Agent
3. **LangGraph** → LangChain SQL Agent
4. **SQL Agent** → PostgreSQL
5. **Все LLM вызовы** → LangFuse (трассировка)
6. **Метрики** → Prometheus → Grafana

## Возможности стека

### ✅ Плюсы
- Полный контроль над каждым компонентом
- Отличная observability
- Гибкость в настройке workflow
- Стандартные инструменты Python экосистемы
- Детальная трассировка всех операций

### ⚠️ Особенности
- Требует понимания LangGraph концепций
- Больше кода для интеграции компонентов
- Ручная настройка связей между сервисами

## Сложность
**Средняя** - требует знания Python, LangChain, Docker
