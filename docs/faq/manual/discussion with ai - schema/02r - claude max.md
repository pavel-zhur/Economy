
Отличное описание! Я вижу ключевую проблему: нужен баланс между **простотой управления** и **мощностью планирования**. Вот несколько элегантных решений:

## Ключевая идея: "Умные ведра с автоматикой"

### Основная концепция

**Plan** - это "умное ведро" с правилами поведения:
```python
class Plan:
    name: str
    type: PlanType  # FUND, GOAL, EXPENSE_BUDGET, INCOME_SOURCE
    
    # Правила наполнения (автоматика)
    auto_fill_rules: List[FillRule]  
    
    # Правила трат (автоматика) 
    auto_spend_rules: List[SpendRule]
    
    # Приоритет (для автораспределения излишков)
    priority: int
    
    # Цель (если есть)
    target_amount: Optional[Money]
    target_date: Optional[Date]
```

### Ключевое решение №1: Правила вместо ручной работы

**FillRule** - как план наполняется:
```python
# "20% от всех доходов автоматически сюда"
FillRule(source="income.*", percentage=20)

# "Каждые выходные 50$ на развлечения"  
FillRule(amount=50, schedule="weekly:weekend")

# "Остаток после обязательных трат - в накопления"
FillRule(source="surplus", percentage=100, priority=LOW)
```

**SpendRule** - как план тратится:
```python
# "Автоматически покрывает все расходы категории 'еда'"
SpendRule(target="category:food", auto=True)

# "Максимум 200$ в неделю на карманные"
SpendRule(amount=200, schedule="weekly", limit=True)
```

### Ключевое решение №2: Временные проекции

**TimeProjection** - автоматически генерируемые снимки:
```python
class TimeProjection:
    plan_id: str
    date: Date
    balance: Money
    scenario: ScenarioType  # OPTIMISTIC, PESSIMISTIC, REALISTIC
    
    # Откуда пришли деньги в этом периоде
    inflows: List[MoneyFlow]
    
    # Куда ушли деньги в этом периоде  
    outflows: List[MoneyFlow]
```

Система автоматически "прокручивает" все правила вперед по времени и строит проекции.

### Ключевое решение №3: Умное автолинкование

**TransactionMatcher** - автоматически предлагает план для транзакции:
```python
# По категории: "еда" → план "Продукты"
# По сумме: 1000$ → план "Крупные покупки" 
# По паттерну: "Зарплата" → автораспределение по правилам
# По умолчанию: → план "Нераспределенное"
```

Пользователь просто **подтверждает** предложения системы или **быстро корректирует**.

### Ключевое решение №4: Сценарии как модификаторы

```python
class Scenario:
    base_scenario: str = "realistic"
    modifiers: List[ScenarioModifier]

# Пессимистичный = реалистичный - 20% доходов + 10% расходов
ScenarioModifier(type="income", multiplier=0.8)
ScenarioModifier(type="expense", multiplier=1.1)
```

### Ключевое решение №5: Микро vs Макро автоматически

**Микро-режим** (до 3 месяцев):
- Точные даты транзакций
- Учет календарных нюансов
- Детальное планирование по дням

**Макро-режим** (свыше 3 месяцев):
- Агрегация по месяцам/кварталам
- Усредненные потоки
- Общие тренды

Система **автоматически** переключается между режимами в зависимости от горизонта планирования.

## Элегантная модель данных

```python
# Основные сущности
Plan              # Умное ведро с правилами
Transaction       # Фактическая операция  
WalletSnapshot    # Инвентаризация кошелька
TimeProjection    # Автопроекция плана во времени

# Правила автоматики
FillRule          # Как план наполняется
SpendRule         # Как план тратится  
DistributionRule  # Как излишки распределяются

# Сценарии
Scenario          # Набор модификаторов
ScenarioModifier  # Изменение параметров

# Связки
PlanTransaction   # Мягкая связь план-транзакция
```

## Пример простого workflow:

1. **Создаю план "Продукты":**
   ```
   Тип: Расходный бюджет
   Автонаполнение: 300$ каждые 2 недели  
   Автотрата: Покрывает категорию "еда"
   ```

2. **Создаю план "Отпуск":**
   ```
   Тип: Цель накопления
   Цель: 2000$ к июню
   Автонаполнение: 10% от зарплаты + излишки с приоритетом 2
   ```

3. **Система автоматически:**
   - Строит проекции на год вперед
   - Показывает, хватит ли денег на отпуск
   - Предлагает корректировки приоритетов
   - Автолинкует новые транзакции

4. **Я делаю только:**
   - Подтверждаю автолинкинг транзакций  
   - Иногда корректирую приоритеты
   - Добавляю новые планы простыми формами

## Проверка целостности трех слоев:

```python
def check_integrity(date: Date):
    wallet_total = sum(WalletSnapshot.at_date(date))
    transaction_total = sum(Transaction.balance_at(date))  
    plan_total = sum(Plan.balance_at(date))
    
    assert wallet_total == transaction_total == plan_total
```

Эта модель решает все твои задачи, но **убирает сложность** через автоматизацию рутины и **умные дефолты**.
